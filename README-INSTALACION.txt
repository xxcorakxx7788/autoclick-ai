
=== AutoClick AI Pro - ANDROID 11+ (Android 11,12,13,14,15) ===

OPCION 1 - SIN INSTALAR NADA (RECOMENDADA - 2 MIN):
1. Crea cuenta gratis en github.com
2. Crea nuevo repositorio privado, sube TODO este ZIP
3. Anda a pestaña "Actions" > Veras "Build APK Android 11+" > Run workflow
4. Espera 2-3 min, descarga el artifact "AutoClickAI-Pro-Android11+"
5. Tendras app-debug.apk lista para instalar en tu celu

OPCION 2 - Con Android Studio:
Importa y dale Run como antes.

COMPATIBILIDAD:
- minSdk 30 = Android 11
- targetSdk 34 = Android 14/15
- Funciona en Android 11,12,13,14,15
- No necesita root

INSTALACION APK EN CELU:
1. Pasa la APK a tu celu
2. Abrela, permite instalar de origen desconocido
3. Ajustes > Accesibilidad > Activa AutoClick AI Pro
4. Si Android 12+ pide "Mostrar sobre otras apps", activalo tambien
5. Abre AutoClick AI Pro, escribe objetivo, INICIAR, minimiza y abre la otra app
