
# AutoClick AI Pro - Proyecto Completo

## QUE ES:
App Android inteligente que lee la pantalla de OTRAS APPS y decide sola donde clickear.

## INSTALACION RAPIDA (2 min):
1. Descarga Android Studio
2. File > New > Import Project > Selecciona esta carpeta AutoClickAI-Pro
3. Conecta tu celu con Depuración USB activada
4. Dale a RUN (Shift+F10)
5. En tu celu: Ajustes > Accesibilidad > AutoClick AI Pro > Activar

## USO:
1. Abre la app AutoClick AI Pro
2. Escribe: "click en COMPRAR, cerrar anuncios"
3. Dale INICIAR IA
4. Minimiza y abre Instagram, juego, tienda, etc.
5. La IA detecta y clickea sola con retardo humano y anti-detección.

## INTELIGENCIA:
- No usa coordenadas fijas, busca nodos por texto/descripción
- Diccionario de sinónimos (BUY=COMPRAR)
- Prioridad: Cerrar anuncios > Objetivo principal
- Anti-detección: ±15px aleatorio + delay 300-1200ms
